O Firebase recusou a conexão. Siga os passos abaixo para liberar o acesso.

Procedimento:

  1. Acesse o Console do Firebase.
  2. Vá em Firestore Database > Rules.
  3. Substitua pelo código abaixo e clique em Publish.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
